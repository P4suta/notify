# Support

Use [GitHub Discussions](https://github.com/P4suta/notify/discussions) for setup,
configuration, deployment, migration, and usage questions. Include the commit
SHA, deployment model, and redacted `notify doctor` output when relevant.

Use issues only for reproducible defects and scoped feature proposals. Use
[private vulnerability reporting](https://github.com/P4suta/notify/security/advisories/new)
for security concerns.

Notify is community-supported and has no guaranteed response time or commercial
support agreement.
